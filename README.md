# StaySure AI - Hotel Booking Cancellation Risk Predictor

This is my Machine Learning for Developers project.

The project uses a hotel booking cancellation dataset to build a machine learning model that predicts whether a hotel booking is likely to be cancelled.

## Project Status

Project setup in progress.

## Dataset

Dataset: Hotel Booking Cancellation Prediction  
Source: Kaggle  
Link: https://www.kaggle.com/datasets/youssefaboelwafa/hotel-booking-cancellation-prediction

## Machine Learning Task

This is a binary classification project.

Target column: is_canceled

Possible outcomes:
- 1 = Canceled
- 0 = Not_Canceled
